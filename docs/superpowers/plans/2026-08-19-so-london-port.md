> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract the clean shortobsessions.com site (umbrella shell + `anna-atkins` + `tshirts` parts) from the messy `studio-tools` repo into this fresh `so.london` repo, leaving all tools/pipeline behind.

**Architecture:** One Astro static site. An umbrella shell (landing `/`, `/about/`, shared `Nav`/`BaseLayout`/tokens) plus two self-contained obsession "parts": `/anna-atkins/` (a standalone reader page importing generated JSON + serving `book/` images) and `/tshirts/` (Shopify cart-permalink page). Copy-based migration (fresh git history), verified with `pnpm build` + `pnpm preview` + Playwright screenshots.

**Tech Stack:** Astro 6+ (vanilla output, no client framework), pnpm, Node 24, sharp (for `astro:assets` image optimization). Deploys to GitHub Pages via Actions.

**Spec:** `docs/superpowers/specs/2026-08-19-so-london-port-design.md`

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages:    write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version-file: .nvmrc
          cache: pnpm
      - name: Install dependencies
        run: pnpm install --frozen-lockfile
      - name: Build site
        run: pnpm build
        env:
          PUBLIC_SHOPIFY_DOMAIN: ${{ secrets.SHOPIFY_DOMAIN }}
      - uses: actions/configure-pages@v5
      - name: Upload dist/ as the Pages artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: ./dist

  deploy:
    runs-on: ubuntu-latest
    needs: build
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```
