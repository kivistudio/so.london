# Inspirations

A running list of rabbit holes, places, and people that shape _short obsessions_.

## Inspired by

- [Marginalia](https://www.marginalia-search.com) — a search engine for the
  non-commercial, human-made web
- [Color-ville](https://color-ville.com/) — where these site colours came from
- [gwern.net](https://gwern.net/)
- [Tufte CSS](https://edwardtufte.github.io/tufte-css/)
- [Atlantic 1866](https://atlantic-1866.com/) — "visualizing information and
  shipping in the Victorian Age", and "an experiment in using AI to make
  digital history"
- [Werner's Nomenclature of Colours](https://www.c82.net/werner/) — the initial
  inspiration for [Anna Atkins](/anna-atkins/), which kick-started
  _short obsessions_
- [Jost](https://indestructibletype.com/Jost.html) — the typeface
  _short obsessions_ is set in
